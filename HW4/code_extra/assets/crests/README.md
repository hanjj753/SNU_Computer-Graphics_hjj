# House crest textures

The four PNGs use the detailed, classic heraldic designs with the house animal,
shield, helmet, mantling and name ribbon. Their style follows the user's
[Logoshirt four-house board reference](https://www.logoshirt-shop.de/en/Breakfast-Boards/Harry-Potter-Four-Houses-Set-of-4-Breakfast-Boards-Retro.html).
These replace the earlier, simpler pin-style shield images.

The downloaded image pixels are unchanged. These are the original RGBA downloads,
not checkerboard preview images. `metadata.json` records sizes, source URLs and UV
bounds around each crest. Pixels with alpha below 0.5 are discarded in the scene
shader, exposing the cloth behind the print. The source pages label these assets
for non-commercial use; they are not CC0 assets.
